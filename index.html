fib(30) makes about 2.7 million calls and runs fine. sum(100000) makes only 100,000 calls and crashes with “Maximum call stack size exceeded”. Why?

The call stack at any moment is exactly the path from the root of the call tree to the call that is running now (highlighted below). Width costs time, depth costs stack.
